# Middle East Regional Academy page (draft concept)

Proposed regional landing page for the UN Global Compact Academy (academy.unglobalcompact.org), prepared by Global Compact Network Lebanon (UNGCNL) comms team. Hosted on GitHub Pages from this repo for review. It is a draft concept, not an official page.

## Files
- `index.html`: the whole page (HTML, CSS, JS in one file). All text lives in the `T` object in the script, with `en` and `ar` keys. Edit copy there, not in the HTML.
- `img/`: banner photo, course thumbnails, case study images, Country Network logos (English and Arabic versions for Lebanon and Saudi Arabia), UN Global Compact emblem.

## Design rules (keep these)
- Must look exactly like the live Academy (a Litmos LMS): white background, Roboto, navy #1E3250, SDG colour strip at top, Academy nav, navy search band, white uppercase hero buttons with shadow, Learning Library list rows with blue pills, dashboard-style training cards (184px, grey footer bar), Case Library cards with navy folded corner.
- Top nav must stay identical to the real Academy (no "Middle East" tab). The page is reached via the breadcrumb "Learning Library / Middle East Regional Academy".
- Arabic uses Noto Sans Arabic and full RTL. Language switch is the globe menu at top right.
- Filters (Content Type, Topic tree, Languages) mirror the real Library. Languages limited to Arabic, English, French. Checkboxes are custom white boxes.
- No footer, no bottom banner, no credits line.

## Writing rules
- British English spelling, UN Editorial style: "United Nations Global Compact" on first mention, then "UN Global Compact", never "UNGC". "Ten Principles", "Global Goals" for business audiences, "Governments" capitalised, "programme".
- No em dashes and no "AI-style" phrasing.
- Arabic: native-quality Modern Standard Arabic. The page uses الاتفاق العالمي للأمم المتحدة (matches the Network logos). The Academy's own SPARK text uses الميثاق العالمي; final term still to be confirmed with the regional team. SPARK course titles are quoted exactly as on the Academy.

## Page sections (in order)
Nav, breadcrumb, search band, hero (title, subtitle, 4 buttons), welcome narrative + 3 value points, How to Get Started (4 steps), Regional Learning Library (filters + 5 items), SPARK 2026: Arabic Track lane (6 items), Case Studies from the Region (4 MENA case studies linking to the Academy Case Library, filtered link: https://unglobalcompact.org/academy/case-library?text=&region%5B5%5D=5), Country Networks (Jordan, Lebanon, Saudi Arabia, UAE; Kuwait removed on purpose).
